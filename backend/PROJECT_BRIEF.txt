1. PROJECT OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
This backend serves as the authoritative, secure REST API and administrative
engine for Holiness Revival Movement Worldwide (HOREMOW). The platform powers
the public website and the private administration portal.

Core Responsibilities:
- Authoritative persistence for sermons, devotionals, events, publications,
  fellowship locations, and ministry teachings.
- Publication lifecycle enforcement: drafts and scheduled content are strictly
  invisible to public visitors until explicitly approved and published.
- Server-authoritative donation processing with Paystack and PayPal.
- Automated donor appreciation email dispatch via Resend upon confirmed payment.
- Append-only security audit ledger tracking all administrative actions.
- Anti-spam, XSS sanitization, SSRF protection, and rate-limiting across all public inputs.


2. SYSTEM ARCHITECTURE & COMPONENT STACK
--------------------------------------------------------------------------------
- Runtime: Python 3.13 (64-bit)
- Framework: Django 5.1 & Django REST Framework 3.15
- Database: PostgreSQL on Supabase (with SQLite fallback for local unit tests)
- Authentication: SimpleJWT with short-lived access tokens (15m), rotating refresh
  tokens (7d), and immediate revocation/blacklisting upon logout.
- Password Hashing: Argon2 (Argon2PasswordHasher) — memory-hard, GPU-resistant.
- Email Dispatch: Resend REST API (resend SDK) with Django EmailBackend fallback.
- Media Storage: Cloudinary API with server-generated signed upload parameters.
- Payment Gateways: Paystack (HMAC-SHA512 webhooks) & PayPal (REST API).
- Security Tools: Bandit (AST security audit), Ruff (linter/formatter), Bleach.


3. SECURITY ARCHITECTURE (DEFENSE IN DEPTH)
--------------------------------------------------------------------------------
a. Zero-Trust API Boundary:
   - The frontend is considered untrusted. All validation, state transitions,
     and permission checks occur server-side.
b. Strict Transport & Headers:
   - HTTP Strict Transport Security (HSTS) with 1-year preload.
   - X-Frame-Options: DENY (clickjacking defense).
   - X-Content-Type-Options: nosniff (MIME sniffing defense).
   - SameSite=Strict cookies with HttpOnly and Secure flags.
   - CORS origin allowlists restricted to authorized frontend domains.
c. Authentication & Identity:
   - Account Lockout: 3 consecutive failed login attempts lock the account
     for 15 minutes.
   - Brute-Force Throttling: Login endpoint throttled to 5 requests/minute.
d. Financial Integrity & Idempotency:
   - Server-side checkout initiation creates unique internal transaction records
     with idempotency keys.
   - Paystack webhook validates raw payload signature using HMAC-SHA512.
   - Database row-level locking (select_for_update) inside atomic transactions
     prevents race conditions from duplicate webhook delivery.
   - Amount and currency are mathematically verified against internal records
     before marking transactions SUCCESSFUL.
e. Donor Appreciation via Resend:
   - Automated multi-part (HTML & text) email receipts sent via Resend API.
   - Email headers sanitized against CRLF injection attacks.
   - Donor email addresses masked in logs (e.g. d*****h@example.com).
f. Input Sanitization & Abuse Mitigation:
   - Comments defanged with Bleach (strips scripts and styles entirely).
   - Comments default to PENDING moderation queue.
   - Contact forms feature hidden honeypot fields to drop bot scrapers silently.
   - External media URLs verified against domain whitelists (SSRF defense).
g. Append-Only Audit Logging:
   - Every administrative write, role change, content publish, and financial
     export is permanently logged with actor email, IP address, user agent,
     and correlation Request-ID.

6. SEEDING & ADMINISTRATIVE SETUP
--------------------------------------------------------------------------------
1. Initialize Database Schema:
   python backend/manage.py migrate

2. Seed Official Ministry Data:
   python backend/manage.py seed_ministry_data
   (Seeds official HOREMOW profile, Pastor Paul Rika, Evangelist Linda Paul Rika,
   foundational doctrines, default categories, and active donation projects).

3. Create Super Administrator:
   python backend/manage.py create_admin --email admin@horemow.org --password <SECURE_PASSWORD>
